写后端,也写把后端串起来的那一层:领域怎么拆、链路怎么异步、调度怎么不出错。
选型偏好简单可维护,新东西先在最细的一条链路上跑通,再谈推广。

### 关注方向

- **架构与调度** — 长链路的领域拆分、幂等与重试、任务依赖与失败恢复
- **数据链路** — 业务库到数仓的取数路径,以及同一指标只允许一种口径
- **AI 工程化** — 把 LLM 放进真实研发流程:可观测、可回退、成本算得清
