### 在忙什么

- **企业系统架构** — 多仓多平台订单链路的领域拆分、异步编排与调度可靠性
- **AI 工程化落地** — 把 LLM 接进真实研发流程,不追概念,只求上线能用
- **工具链沉淀** — 一套自己能长期维护的脚手架,而不是每周换一个新框架
